## Initial release
- Hands-first WebXR focus desk for Meta Quest: pinch-to-move task cards across Next up / Now / Done lanes.
- Pinch-orb focus timer (5, 15, 25 min) and palm-up wrist menu.
- Passthrough mixed reality (immersive-ar) with immersive-vr fallback; controller and mouse fallbacks.
- Local on-device storage; single static index.html on GitHub Pages.
